# SimpleSample

Minimal Python script that prints the current local time (with timezone) and UTC.

## Requirements

- Python 3.10+ (stdlib only; no extra packages)

## Run

```bash
python3 main.py
```

Example output:

```
Local time: 2026-10-09 21:00:00 UTC (UTC+00:00)
UTC:        2026-10-09 21:00:00 UTC
```
